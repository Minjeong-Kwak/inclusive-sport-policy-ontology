# inclusive-sport-policy-ontology

An OWL ontology that formalizes intersectionality as a reusable ontology
design pattern for representing multi-layered vulnerable populations in
inclusive sport participation policy.

## Overview

This ontology demonstrates how the combination of multiple social positions
(e.g., age, migration background, disability, gender) can be represented at the
instance level and connected to policy information through a single relational
path. It combines three design principles — selective (limited) disjointness,
a target-group relational anchor, and cross-domain modular design — using
standard OWL 2 DL constructs rather than any new reasoning mechanism. The
ontology was validated on Korean inclusive sport participation policy data and
checked for consistency with the HermiT reasoner.
